## `M:CP.ReactiveUI.Primitives.Windows.Desktop.Display.Dpi.Forms.FormsDpiExtensions.AttachDpiHandler(System.Windows.Forms.Form)`

Handle DPI changes for the specified Form Using this DOES NOT enable dpi scaling in the non client area, for this you will need to call: DpiHandler.TryEnableNonClientDpiScaling(this.Handle) from the WndProc in the WM_NCCREATE message. Prefer AttachDpiAwareBehavior when the form handle should be created in a DPI-aware context.
